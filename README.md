# 📰 News Cloud App

A Flutter-based news app that displays categorized news using a clean and user-friendly UI.

## 📱 Features

- 🧠 State management with `flutter_bloc`
- 🌐 Networking using `dio`
- 🎠 Category selection with `carousel_slider`
- 🖼️ Cached images using `cached_network_image`
- 🧩 Shows a default placeholder when no image is available

## 🛠️ Tech Stack

| Tool                   | Use                                      |
|------------------------|------------------------------------------|
| `flutter_bloc`         | For managing state                      |
| `dio`                  | To handle HTTP requests                 |
| `carousel_slider`      | To show category list in slider         |
| `cached_network_image` | To cache and display images efficiently |

## 🚀 How It Works

1. Categories are displayed in a horizontal slider.
2. When a category is selected, related news articles appear below.
3. If an article has no image, a default image is shown instead.
